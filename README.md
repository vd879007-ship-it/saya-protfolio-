# Sayasri Balaji React Portfolio

## Run the project
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in that folder.
4. Run:
   npm install
5. Then:
   npm run dev

You can also use:
   npm start

Open the localhost URL shown in the terminal.

This is a Vite + React project using JSX components and separate CSS files.
